# Rejected Google Trends export attempt

These fourteen files were collected on 2026-08-04 but are not used in the
analysis. Their requested ranges began on the first Sunday in each event window,
which supplied only one daily observation for the first Sunday-ending weekly
mean. The corrected exports in `data/raw/google_trends/` begin on the preceding
Monday and contain 25 complete seven-day weeks. The rejected files are retained
to preserve the collection audit trail.
